    Penjelasan Teknologi yang Digunakan

    Ringkasan alat dan konsep yang dipakai untuk membuat aplikasi ini.

    Git dan GitHub

    Git adalah sistem kontrol versi yang mencatat setiap perubahan kode sebagai commit, sehingga riwayat pekerjaan bisa ditelusuri dan dikembalikan. GitHub menyimpan repository itu secara online. Di proyek ini aku memakai branch terpisah untuk tiap fitur, menggabungkannya lewat Pull Request, melakukan push dan pull, serta menyelesaikan merge conflict pada baris judul halaman. File .gitignore mencegah node_modules, dist, dan .env ikut terunggah.

    npm

    npm adalah package manager untuk mengunduh dan mengelola library. Daftar package dicatat di package.json, dan versi persisnya dikunci di package-lock.json. Di scripts ada perintah npm run dev, npm run build, dan npm run preview.

    • dependencies: package yang dibutuhkan aplikasi saat berjalan (proyek ini belum memakainya).
    • devDependencies: alat bantu pengembangan, yaitu typescript dan vite.
    • Semantic versioning (MAJOR.MINOR.PATCH): tanda ^ mengizinkan update minor dan patch, sedangkan ~ hanya patch.
    TypeScript

    TypeScript adalah JavaScript dengan sistem tipe, sehingga kesalahan data terdeteksi sebelum aplikasi dijalankan. Contoh yang dipakai di kode:

    • Primitive types: string, number, boolean.
    • Array: Tugas[] untuk daftar tugas.
    • Interface: Tugas dan AppConfig menentukan bentuk data.
    • Type alias dan union type: StatusTugas = "Belum Selesai" | "Selesai".
    • Generics: cariBerdasarkanId<T>, simpanData<T>, dan ambilElemen<T>.
    Vite

    Vite adalah build tool. Saat pengembangan, npm run dev menjalankan server lokal yang cepat dan langsung memuat perubahan. Untuk produksi, npm run build menghasilkan folder dist berisi file HTML, CSS, dan JavaScript yang sudah dioptimalkan dan siap diunggah.

    Environment variables

    Konfigurasi aplikasi disimpan di file .env (nama, versi, dan author aplikasi) dan dibaca lewat import.meta.env. File .env tidak diunggah ke GitHub, sedangkan .env.example diunggah sebagai contoh format. Di Vite, variabel berawalan VITE_ ikut tertanam di hasil build dan bisa dilihat siapa pun di browser, sehingga hanya boleh berisi data non-rahasia. Password dan API key rahasia tidak boleh ditaruh di sini.

    Compiler, transpiler, dan bundler
    • Compiler menerjemahkan kode ke bentuk lain dan memeriksa kesalahannya. Di proyek ini, tsc memeriksa tipe TypeScript (tsc && vite build berhenti bila ada error tipe).
    • Transpiler menerjemahkan kode ke bahasa sejenis pada tingkat abstraksi yang sama. Kode TypeScript diubah menjadi JavaScript biasa karena browser hanya memahami JavaScript.
    • Bundler menggabungkan banyak modul (main.ts, config.ts, tugas-service.ts, dan lainnya) beserta CSS menjadi sedikit file yang kecil di folder dist. Vite berperan sebagai bundler sekaligus menjalankan proses transpile.
